## slide-21

Context-free skill makes it reusable

Previous: Hardcode JB Agentic meetup-specific context into the skill.

talk-subtitle-polish skill input is meetup/<talk>.raw.srt.

Now: Reusable for any talk-show videos e.g. podcasts, talks, interviews.

subtitle-polish skill input is a raw unpolished subtitle file.

meetup/post-edit.runbook.md configures input as meetup/<talk>.raw.srt.
podcast/post-edit.runbook.md configures input as podcast/<show>.raw.vtt.
